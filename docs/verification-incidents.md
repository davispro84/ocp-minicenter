# OCP Mini-Center — Verification Incident Log

Every time a technical claim was proposed (almost always via an outside AI tool used alongside this one on the same project) and rejected because it wasn't actually checked against a primary source. Kept as a running log rather than scattered inline notes, because this turned out to be a recurring pattern within a single working session, not a one-off — worth tracking as its own record.

**Purpose:** this log is the receipts for the verification methodology described in `CLAUDE.md` — proof it actually catches things, not just a policy statement. Also useful raw material if this project is ever discussed as a portfolio/interview example of AI-assisted engineering discipline.

**Pattern across all six:** the common tell is a confident, specific-sounding claim ("I verified," "I pulled the real data," "I searched") with no actual source document, file, or link attached — often converging suspiciously well with whatever number was already assumed, or silently swapping a model number/figure that was previously locked. Treat any such claim, from any tool, as a lead to verify, never as a fact to act on.
